# Login Test Cases

## TC-001: Valid Login
**Objective:** Verify login with valid credentials.

**Steps:**
1. Open the login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click Login.

**Expected Result:** User successfully logs in.

## TC-002: Invalid Password
**Objective:** Verify login with an incorrect password.

**Steps:**
1. Open the login page.
2. Enter a valid username.
3. Enter an incorrect password.
4. Click Login.

**Expected Result:** Login is rejected and an error message appears.
## TC-003: Empty Password
**Objective:** Verify login behavior when the password is empty.

**Steps:**
1. Open the login page.
2. Enter a valid username.
3. Leave the password field empty.
4. Click Login.

**Expected Result:** Login is rejected and a password-required message appears.
